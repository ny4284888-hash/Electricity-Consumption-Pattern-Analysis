# Electricity Consumption Pattern Analysis

## Project Overview
This project analyzes electricity consumption patterns using Python and Data Analytics. It uses a 30-day synthetic electricity dataset to understand daily usage, compare weekdays and weekends, identify peak consumption days, and detect unusual readings.

## Project Objectives
- Analyze daily electricity consumption.
- Calculate total and average electricity usage.
- Compare weekday and weekend consumption.
- Identify the highest and lowest consumption days.
- Detect unusual readings using the IQR method.
- Visualize electricity consumption patterns.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- CSV Dataset

## Dataset Information
- Dataset Type: Synthetic (practice data)
- Duration: 1 October 2026 – 30 October 2026
- Total Records: 30
- Measurement Unit: kWh per day
- Sampling Interval: Daily

The analysis shows that average electricity consumption is higher on weekdays than weekends in this synthetic dataset. The project demonstrates how Python can be used to analyze and visualize electricity consumption patterns.
